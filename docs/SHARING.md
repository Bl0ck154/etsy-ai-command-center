## One-line directory description

Etsy AI Command Center is a self-hosted Etsy shop dashboard with manual seller tools and a tool-using AI copilot that prepares listing and media changes for owner approval.

## Short launch blurb

We've published an early open-source preview of AI Command Center for Etsy sellers. It brings manual listings, inventory, orders and media tools into one dashboard, alongside an AI assistant that can inspect available shop context and prepare actions for review.

The repository includes a synthetic interactive demo, setup instructions and the source of the application. Real Etsy access requires your own approved API credentials. Some advanced message and social workflows still depend on external services, so this is a developer preview rather than a production-certified release.
