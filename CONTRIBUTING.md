# Contributing

Issues and pull requests are welcome.

For a bug report, include the affected page or API route, expected behavior, actual behavior, reproduction steps, and the relevant version. Use synthetic Etsy listings or redacted screenshots.

Before submitting a PR:

1. Keep changes focused and describe why they help an Etsy seller.
2. Run `npm run check` and any relevant unit tests.
3. Do not add production URLs, shop-owner names, access tokens, account IDs or customer messages to tests and documentation.
4. Keep irreversible actions behind appropriate review and authorization gates.
5. Update the user-facing documentation when behavior changes.

For design proposals, start with a clear user workflow and explain which parts work without AI.
